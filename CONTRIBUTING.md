# Contributing to Vigilo Showcase

Thank you for your interest in Vigilo.

## 1. Nature of This Repository

This repository (`vigilo-showcase`) is an **independent public technical showcase and architectural documentation archive**. It is **not** an open-source development workspace, and it does not host the application's implementation source tree.

As such, typical open-source pull requests proposing feature additions, code refactoring, or dependency changes to the application cannot be merged here.

---

## 2. Permitted Contributions

We welcome contributions specifically focused on improving the **accuracy, clarity, and completeness of the documentation**:

1. **Typographical & Grammatical Corrections:** Fixing errors or awkward phrasing in Markdown documentation.
2. **Broken Internal Link Fixes:** Reporting or patching broken intra-repository markdown references or anchor links.
3. **Diagram Clarifications:** Suggestions for improving the legibility or semantic clarity of public architecture diagrams.
4. **Factual Alignment:** Highlighting discrepancies between documented specifications and observed mobile systems behaviors.

### Submitting Documentation Improvements

1. Ensure the change strictly concerns Markdown documentation or public diagram files.
2. Submit a concise Pull Request with a clear explanation of what is being corrected and why.
3. Do not include application code, APKs, decompiled code, or third-party proprietary assets.

---

Contributions to the **private Vigilo application repository**, proprietary machine learning datasets, or telematics engine are managed separately and require formal authorization.
