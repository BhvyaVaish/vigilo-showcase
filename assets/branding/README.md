# Vigilo Brand Assets

This directory contains verified visual branding and identity assets for the **Vigilo** project.

---

## Brand Identity

* **Name:** Vigilo (derived from the Latin verb *vigilō*, meaning *"I watch"*, *"I stay awake"*, or *"I remain alert"*).
* **Emblem:** A geometric shield and sentinel owl motif rendered in high-contrast safety amber, gold, and obsidian tones, representing continuous vigilance, defensive integrity, and autonomous night-time protection.
* **Palette:**
  * **Safety Crimson:** `#E53935` / `rgb(229, 57, 53)` (Emergency countdowns, high-G collision alerts)
  * **Amber Caution:** `#FFA000` / `rgb(255, 160, 0)` (Bystander alert mode, suspected impact warnings)
  * **Obsidian Black:** `#121212` / `rgb(18, 18, 18)` (Primary cockpit dashboard, low-glare driving background)
  * **Clean Steel:** `#ECEFF1` / `rgb(236, 239, 241)` (High-legibility telemetry typography)
