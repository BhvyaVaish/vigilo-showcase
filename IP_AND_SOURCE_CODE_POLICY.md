# Intellectual Property & Source Code Policy

## 1. Purpose of This Showcase Repository

This repository (`vigilo-showcase`) is a dedicated **public technical documentation and systems architecture showcase** for the **Vigilo** road safety platform. It has been prepared for presentation to technical reviewers, industry evaluators, systems engineers, and potential technology partners.

This repository serves to document the problem space, architectural choices, sensor fusion heuristics, cryptographic verification pipelines, and verified capabilities of the Vigilo prototype.

---

## 2. Distinction Between Public Documentation and Private Implementation

* **Public Repository (`vigilo-showcase`):** Contains conceptual documentation, systems architecture diagrams, workflow descriptions, technology inventories, and verification guides. It does **not** contain the application source tree, private backend logic, machine learning training sets, or compiled Android application packages (`.apk` / `.aab`).
* **Private Repository (`Vigilo`):** The complete Android implementation, build configurations, test suites, and internal assets remain in a private repository under active development and evaluation.

The private status of the core implementation is maintained to protect the project's intellectual property, custom sensor fusion logic, and security architecture during ongoing testing and review.
