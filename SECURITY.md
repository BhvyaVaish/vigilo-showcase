# Security Policy

## 1. Scope of This Repository

This repository (`vigilo-showcase`) consists exclusively of **public technical documentation, architectural specifications, and diagrams** for the Vigilo prototype.

* **In Scope:** Inaccuracies in security specifications, accidental exposure of configuration artifacts, or documentation ambiguities that could lead to insecure integration patterns.
* **Out of Scope:** Because this repository does **not** host active server endpoints, authentication backends, production API tokens, or compiled software binaries, classic network vulnerability scanning of this repository's assets is inapplicable.

---

## 2. Reporting Suspected Security Concerns

If you identify a security or privacy vulnerability in any documented architectural pattern or suspect that sensitive material has been inadvertently included in this public documentation repository, please report it responsibly.

---

## 3. Expectations and Disclaimer

* Reports will be reviewed in good faith by the author.
* No formal response timeline, Service Level Agreement (SLA), or monetary bug bounty program is provided for this educational prototype repository.
* The underlying Vigilo application implementation is maintained privately under ongoing security and safety hardening.
